# Tixify — Proposed Two-Month Work Plan

Dates should be confirmed with the guide. This is a proposed schedule, not evidence that work occurred on these dates.

| Week | Focus | Deliverable |
|---|---|---|
| 1 | Scope discussion and codebase audit | Confirmed scope, module checklist |
| 2 | Database and clean local setup | Schema review, setup notes |
| 3 | Authentication and movie discovery | Verified API/UI test evidence |
| 4 | Theatre, screen and show management | Endpoint docs and tests |
| 5 | Seat selection and booking consistency | Seat-state/duplicate-booking tests |
| 6 | Confirmation, pricing summary and history | Verified workflow evidence |
| 7 | Integration tests, fixes and docs | Test log, updated README |
| 8 | Demo and guide review | Final report and sign-off |

## Risks and mitigation
- Verify React/frontend alignment with the submitted scope.
- Test double-booking behavior before claiming reliable seat locking.
- Keep secrets out of Git.
- Obtain guide approval before scope expansion.
- Prioritize repository completeness, accurate documentation and sign-off.
